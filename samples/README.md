# Samples

Place small local test clips here for smoke testing.

Supported inputs:

- `.mp4`
- `.mov`
- `.m4v`
- `.avi`
- `.zip` containing `.jpg`, `.jpeg`, or `.png` frames

Do not commit large videos. Keep real clips local, or use a small synthetic/debug clip for CI.

Run:

```bash
python scripts/test_process_local.py
```
